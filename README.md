# Customer Segmentation & Churn Prediction Analysis

## Project Overview

This project analyzes retail banking customer data to identify customer segments and predict customer churn using data analysis and machine learning.

## Objectives

- Analyze customer banking data
- Identify different customer segments
- Predict customer churn
- Identify factors associated with customer churn
- Develop an interactive dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Customer Segmentation
5. Churn Prediction
6. Model Evaluation
7. Streamlit Dashboard
8. Final Insights

## Machine Learning

K-Means clustering is used for customer segmentation.

Logistic Regression is used for customer churn prediction.

## Conclusion

The project provides insights into customer behavior and helps identify customers who may be at risk of churn.
